# Student Grade Calculator

## About the Project
Student Grade Calculator is a beginner-friendly Python project that calculates students' total marks, percentage, grade, and pass/fail status.

## Features
- Accepts student name and subject marks
- Calculates total marks and percentage
- Assigns a grade based on percentage
- Displays pass/fail status
- Validates marks between 0 and 100
- Handles invalid numeric input
- Saves student results in a CSV file
- Supports entering multiple students

## Technologies Used
- Python
- CSV
- Python Standard Library

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python main.py
```

## Grading Scale
- 90% and above: A+
- 80% and above: A
- 70% and above: B
- 60% and above: C
- 50% and above: D
- Below 50%: F

The project uses 50% as its pass threshold for practice purposes.
